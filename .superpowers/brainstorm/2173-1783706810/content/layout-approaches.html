Opção C
Scroll único sem tabs
Remove as tabs. Tudo numa página com seções colapsáveis: KPIs → Pendências críticas → Notas recentes → Playbooks → Contatos → Histórico. Navegação mais simples, mas perde a separação clara de contextos.
Zero navegação por tab Tudo acessível com scroll Pode ficar longo Perde separação clara
Minha recomendação
Opção A — é o menor risco e o maior ganho. A estrutura de tabs já existe, o CS já conhece. O que falta é colocar os indicadores vitais no header (health, CSAT, NPS) e reorganizar o conteúdo de cada tab para ter um propósito claro. Custo baixo, impacto alto.
